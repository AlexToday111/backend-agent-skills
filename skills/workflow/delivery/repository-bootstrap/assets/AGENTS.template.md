# Repository instructions

Inspect documentation, build manifests and scoped instructions before changes.
Preserve conventions. Do not invent commands, versions, features or dependencies.
Never display secrets, rewrite history, or publish without authorization.
Run checks from verified configuration and report actual failures or skips.
Prepare PR descriptions from the Git diff using .github/PULL_REQUEST_TEMPLATE.md.
Do not invoke an LLM API automatically or generate application logic during bootstrap.
